# Architect Portfolio — Tailwind Edition

A multi-page architectural portfolio site built with Tailwind CSS, recreating a set of supplied wireframes as closely as possible.

Part of the ITonlinelearning Tailwind CSS course.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home — hero, statistics, methodology, current projects |
| `projects.html` | Selected Works archive |
| `contact.html` | Contact form and studio details |

## Built with

- **Tailwind CSS v4** via the Play CDN (`@tailwindcss/browser@4`)
- Custom theme colours defined in an `@theme` block
- **CSS Grid** and **Flexbox** for all layout — no absolute positioning
- Archivo (Google Fonts)

## Design direction

Brutalist architectural aesthetic: heavy rules, tight oversized type, monochrome palette, deliberate negative space.

## Running it

Clone the repo and open `index.html` in a browser. No build step — Tailwind is compiled in the browser by the Play CDN.
